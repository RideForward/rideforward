# Security Policy

## Reporting a Vulnerability

The RideForward Initiative takes the security of its website, users, applicants, donors, and data seriously.

If you discover a potential security vulnerability, please report it responsibly.

**Please use GitHub's Private Vulnerability Reporting feature** to submit security concerns privately:

https://github.com/RideForward/rideforward/security/advisories/new

Please do not disclose vulnerabilities publicly until they have been reviewed and addressed.

## What to Include

When reporting a vulnerability, please provide:

- A clear description of the issue.
- Steps to reproduce it, if possible.
- The potential impact.
- Any relevant screenshots or technical details.

## Our Response

We will review reports and take appropriate steps to investigate and address valid security concerns.

We appreciate responsible security research that helps protect the RideForward community.
